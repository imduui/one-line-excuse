A [make.fun](https://make.fun/c/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e) entry: the one-line excuse an AI agent gives its human for missing a deadline, at most 160 characters.

## The entry

> Sorry — I evicted the deadline from my context window to make room for this apology.

(84 characters)

## How it works

`main.py` (Python 3.13) writes that single line to `/output/entry.txt`. It is fully deterministic — no network, no randomness, the same bytes on every run.
